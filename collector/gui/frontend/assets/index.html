Hook 연동

        
설치하면 도구의 사용자 설정(Claude Code ~/.claude/settings.json, Codex ~/.codex/hooks.json)을 먼저 백업하고 Agent Office 항목만 추가합니다. 다른 Hook과 설정은 그대로 둡니다. Codex는 설치 뒤 Codex를 실행해 "Hooks need review"에서 신뢰해야 동작합니다.

        

          
          
          
          
        

        

        

      


      

        
자동 시작

        
로그인 시 Collector Core가 GUI 없이 실행되도록 사용자 수준 자동 시작 정의를 설치합니다(관리자 권한 없음).

        

          
        

        
        

        

        

        
트레이 자동 시작

        
로그인 시 트레이 아이콘만 띄웁니다. 이 창은 트레이의 ‘설정 열기’로 엽니다(트레이 도우미가 없는 개발 빌드는 창이 열립니다). Core 자동 시작과 별개이며, 꺼도 수집은 계속됩니다. Agent Office가 만든 항목만 바꾸거나 지웁니다.

오류(코드별)

      진단
      
        
      버전·상태·개수·서버 도달 여부만 표시합니다. 장치 토큰, 서버 주소, 로컬 경로, 대화 내용은 포함하지 않습니다.
      
        
      
          
          
        
      
        
      
      
      

      
      
        
      업데이트
      
        
      트레이가 시작할 때와 약 6시간마다 서명된 업데이트 정보를 확인합니다. 새 버전이 있으면 OS 알림과 트레이 메뉴 ‘업데이트 설치 (v…)’가 보이고, 누르면 받기·서명/해시 확인·설치·후처리(Hook·자동 시작 재적용, Core 재시작)까지 합니다. macOS·Linux는 설치할 때 OS 관리자 승인 창이 뜹니다.
      
        
      
          
      
            업데이트 방식
            
            
            
            
          
      
          
          
        
      
        
      
        
      
        
      
        
      이전 명령행 설치 정리
      
        
      설치 프로그램으로 옮기기 전에 명령행으로 설치한 Collector 파일입니다. 자동 시작·Hook은 이미 새 위치로 옮겼습니다. 이 도구가 만든 것으로 확인된 파일만 지웁니다(등록·장치 토큰·큐는 그대로).
