Collector

이 창은 Collector Core를 설정하고 상태를 보여 줍니다. 창을 닫아도 자동 시작된 수집은 계속됩니다.

계정·서버

Agent Office 서버 주소를 입력하세요. 로그인은 브라우저에서만 하며 이 앱은 계정 비밀번호를 받지 않습니다.

기기 등록

  1. 웹의 /devices 화면에서 'PC 등록 코드 발급'을 누르면 10분 동안 쓸 수 있는 일회용 코드가 나옵니다.
  2. 받은 코드와 이 PC의 이름을 입력하세요.


        
로그아웃(이 PC 등록 해제)

        
Collector Core가 서버에서 이 PC를 폐기하고, OS 보안 저장소(또는 대체 설정 파일)의 장치 토큰과 등록 정보를 지웁니다. 실행 중인 수집은 몇 초 안에 전송을 멈춥니다.

Hook 연동

        
설치하면 도구의 사용자 설정(Claude Code ~/.claude/settings.json, Codex ~/.codex/hooks.json)을 먼저 백업하고 Agent Office 항목만 추가합니다. 다른 Hook과 설정은 그대로 둡니다. 자동 시작

        
로그인 시 Collector Core가 GUI 없이 실행되도록 사용자 수준 자동 시작 정의를 설치합니다(관리자 권한 없음).

        

          
        

        
        

        

        

        
트레이 자동 시작

        
로그인 시 트레이 아이콘만 띄웁니다. 이 창은 트레이의 ‘설정 열기’로 엽니다(트레이 도우미가 없는 개발 빌드는 창이 열립니다). Core 자동 시작과 별개이며, 꺼도 수집은 계속됩니다. Agent Office가 만든 항목만 바꾸거나 지웁니다.
