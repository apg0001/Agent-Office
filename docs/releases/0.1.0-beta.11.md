# Agent Office 0.1.0-beta.11

> **상태: Beta.** Stable이 아닙니다. 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. 서버·웹 이미지는 GHCR `ghcr.io/apg0001/agent-office-server`·`agent-office-web` `0.1.0-beta.11`으로 냅니다. **Collector는 바뀌지 않았습니다**(최신 Collector는 `collector-v0.1.0-beta.9`).

대상: 0.1.0-beta.10 사용자. 서버·웹 이미지를 교체하고 DB 마이그레이션 0011을 적용합니다(`deploy/upgrade.sh`가 함께 처리). Collector 업데이트는 필요 없습니다.

## 바뀐 것

| 영역 | 내용 | 이슈 |
|---|---|---|
| 팀 화면 PC 이름 | `/teams` 팀 카드에 "이 팀에 내 PC 이름 보이기" 체크 상자(기본 끔). 켜면 그 팀 팀원의 세션 목록·상세에 `이름 · PC 이름`으로 보이고, 끄면 지금처럼 이름만 보임 | #298 |
| 팀 사무실, 내 PC | 팀 사무실에서도 내 장치는 내게 `내 이름 · PC 이름`으로 보여 PC가 여러 대일 때 구분됨. 팀원에게는 옵션을 켜기 전까지 보이지 않음 | #298 |
| 통합 사무실 | 남의 장치는 나와 함께 속한 팀 가운데 그 세션이 보이는 팀에서 소유자가 옵션을 켰을 때만 PC 이름이 보임 | #298 |

옵션은 팀마다 따로이고 본인만 바꿀 수 있습니다. 캐릭터 머리 위 이름표는 사람 이름 그대로이고, 팀 화면의 작업 폴더 이름은 본인에게도 계속 보이지 않습니다.

## 실제로 검증한 것

| 항목 | 근거 |
|---|---|
| 서버 | Ruff, mypy, pytest(PostgreSQL) 504 통과·4 건너뜀: 기본 끔 비노출, 다른 팀으로 새지 않음, 끄면 다시 숨김, 남의 옵션 변경 불가, 마이그레이션 downgrade·재-upgrade |
| 웹 | typecheck, Vitest 167개, 프로덕션 빌드, CI(`CI Gate`, 브라우저 E2E) |

## 검증하지 않은 것(지원한다고 하지 않음)

- 실제 브라우저에서 체크 상자를 켜고 끈 뒤 새로고침했을 때의 표시(상태 연결 일부는 자동 테스트로 덮이지 않음)
- 팀원 계정 2개로 본 실제 팀 사무실 화면

## 알려진 위험

- PC 이름에는 실명·자산 번호가 들어 있을 수 있습니다. 옵션을 켜면 그 팀 구성원 모두에게 보입니다.
- 옵션을 꺼도 이미 화면을 본 팀원의 기억·캡처까지 지울 수는 없습니다.
