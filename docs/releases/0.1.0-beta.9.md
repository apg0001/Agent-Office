# Agent Office 0.1.0-beta.9

> **상태: Beta.** Stable이 아닙니다. 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. Collector는 GitHub Release `collector-v0.1.0-beta.9`로 냅니다. **서버·웹은 바뀌지 않았습니다**(운영 이미지는 `0.1.0-beta.8` 그대로).

대상: 0.1.0-beta.8 사용자. Collector만 업데이트하면 됩니다. 서버 업그레이드·DB 마이그레이션은 필요 없습니다.

## 바뀐 것

| 영역 | 내용 | 이슈 |
|---|---|---|
| 테스트 구역 | Claude·Codex가 셸에서 테스트를 돌리면(`pytest`·`go test`·`npm test`·`npx vitest`·`cargo test`·`make test` 등) 캐릭터가 테스트 구역으로 감. `cd web && npx vitest run`·`bash -lc "go test"`처럼 이어 붙이거나 감싼 명령도 인식 | #280 |
| 회의실 | Claude TodoWrite·계획 모드 진입/종료, Codex `update_plan`이면 회의실로 감 | #280 |
| 개인정보 | 명령은 PC 안에서만 보고 판정 뒤 버림. 서버에는 활동 값(`testing`·`planning`)만 감. 명령 원문·실행 파일 이름·인자는 대기열·서버·로그에 남지 않음 | #280 |

## 검증하지 않은 것(지원한다고 하지 않음)

- 실제 Claude·Codex 세션에서 운영 화면의 테스트 구역·회의실 이동(게시 후 Pi에서 확인 예정)
- 목록에 없는 테스트 도구(그 경우 예전처럼 자리에서 작업)

## 알려진 위험

- 분류는 명령의 실행 파일·하위 명령 이름만 봅니다. 스크립트 안에서 테스트를 돌리는 경우(`./run.sh`)는 테스트로 보지 않습니다.
- 도서관(파일 읽기)·인터넷(웹 검색)은 도구가 금방 끝나 잠깐 들렀다 돌아오는 것이 실제 모습이라 바꾸지 않았습니다.
