# Agent Office 0.1.0-beta.1

> **상태: Beta(2026-10-25 관리자 승인).** 첫 공개 Beta입니다. Stable이 아니며, 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. 서버·웹 이미지는 GHCR `ghcr.io/apg0001/agent-office-server`·`agent-office-web` `0.1.0-beta.1`, Collector 배포물은 GitHub Release `collector-v0.1.0-beta.1`로 냅니다.

대상: 자체 호스팅 운영자(Raspberry Pi·Linux 서버)와 Claude Code·Codex 사용자.

## 검증하지 않은 것(지원한다고 하지 않음)

- 사람이 쓰는 macOS·Windows 데스크톱에서 GUI 화면 조작·브라우저 로그인 클릭·재로그인 후 자동 시작(러너에서는 빌드·실행·등록까지 검증)
- 배포물 코드 서명·macOS 공증·Windows Authenticode(#42), 서명하지 않은 실행 파일의 Gatekeeper·SmartScreen 경고
- macOS·Windows의 실제 Claude Code·Codex 전체 흐름, Codex CLI·Desktop Hook 흐름(#62, #87), 대화형 Claude 세션의 승인 대기
- 실제 GitHub Release에서 받는 자체 업데이트(#44)
- 실제 Google·GitHub OAuth 로그인, 실제 Discord·Telegram·Teams·SMTP 전송
- Tailscale·Cloudflare Tunnel·도메인 자동 HTTPS 실경로
- 72시간 연속 실행: 이 릴리스 시점에 Pi 5에서 진행 중(16시간째 실패·오류 로그 0, 서버 메모리 약 97MiB 유지). 결과는 `docs/operations/performance.md`에 추가합니다(#63)

## 알려진 위험

- **Collector 0.1.0-beta.1은 GitHub Release에서 자체 업데이트를 받지 못합니다**(다운로드 302 리다이렉트를 따라가지 않음, #44). 다음 버전에서 고쳤으며, 0.1.0-beta.1 사용자는 다음 버전을 한 번 수동으로 설치해야 합니다.
- 0.1.0-beta.1 Release의 deb·rpm 파일 이름은 `SHA256SUMS`를 Release에 올린 뒤 이름 변환(`~`→`.`)에 맞춰 교체했습니다(해시는 빌드 결과 그대로).

- Pi에서 SSD에 무거운 I/O가 몰릴 때 저전압 경고가 기록됨 → 공식 5V 5A 전원 권장
- OAuth callback의 `code`·`state`가 프록시 접근 로그에 남을 수 있음(짧은 수명·일회용)
- 감사 로그·이벤트 보존은 서버 시계 기준. 시계가 크게 틀리면 정리 시점이 어긋남
