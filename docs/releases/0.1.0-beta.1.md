# Agent Office 0.1.0-beta.1 (초안)

> **상태: 초안.** 아직 릴리스가 아닙니다. 관리자가 승인하고 `docs/operations/release.md` 절차(이미지 게시 → `main` 병합 → 태그)를 마친 뒤에만 릴리스입니다.

대상: 자체 호스팅 운영자(Raspberry Pi·Linux 서버)와 Claude Code·Codex 사용자.

## 포함 기능

| 영역 | 내용 |
|---|---|
| 서버 | FastAPI + PostgreSQL 17, 이벤트 수집(멱등·순서·속도 제한), 3축 상태 엔진, 실시간 WebSocket(개인·팀·통합), 30일 보존·계정 삭제 |
| 계정 | 이메일 가입·확인·복구, Google·GitHub OAuth, 가입 정책 4종, 관리자 승인, 남용 방지, 감사 로그 |
| 설치 | 콘솔 bootstrap 최초 관리자, 설치 마법사, Caddy 단일 진입점, 원격 접속 가이드(Tailscale 권장) |
| 팀 | 팀·역할·초대·소유권 이전, 소유자 동의 프로젝트 공유, 공유 철회 즉시 반영 |
| 사무실 | 아이소메트릭 Phaser 사무실, 픽셀 캐릭터, 경로·카메라, 생활·퇴근 연출, 상세 패널·계획 진행도·타임라인 |
| 운영 | 준비 상태·지표·보안 점검, 암호화 백업(로컬 7·외부 일7/주4)·복원 시험, 알림(Discord·Telegram·Teams·이메일), 승인형 배포·자동 롤백 |
| Collector(헤드리스) | Hook·transcript 수집, 정규화·중복 제거, SQLite 큐·재전송, 서비스 정의, Hook 안전 설치(Claude) |

| 항목 | 근거 |

| 웹 | Vitest, 실제 Chromium E2E(설치 마법사→사무실→관리→팀→로그인, CI `E2E (browser)`) |
| Collector | `go test -race`, Linux arm64 컨테이너 |
| 이미지 | amd64·arm64 네이티브 빌드(CI), Pi arm64 운영 Compose 실기동 |

| 배포·롤백 | Pi 실측: 0005→0006 업그레이드, 점검 실패 시 DB 다운그레이드 롤백 |

| 성능 | Pi 5 + SSD: 30세션·90에이전트 표시 지연 P95 1.45초, 브라우저 평균 39.8FPS, 서버 재시작 후 WebSocket 3.4초 회복(`docs/operations/performance.md`) |

## 검증하지 않은 것(지원한다고 하지 않음)

- **Collector의 macOS·Windows 실행**, 실제 systemd·launchd·작업 스케줄러 등록, Collector GUI·설치 패키지·자동 업데이트(#40~#44)
- 실제 Claude Code·Codex가 설치된 Hook을 호출하는 전체 흐름(#62), Codex 사용자 수준 Hook 설정 위치(설치는 미리보기만)
- 실제 Google·GitHub OAuth 로그인, 실제 Discord·Telegram·Teams·SMTP 전송
- Tailscale·Cloudflare Tunnel·도메인 자동 HTTPS 실경로, 72시간 연속 실행(1시간까지 실측)
- GHCR 게시 이미지(이 노트 승인 후 게시)

## 알려진 위험

- Pi에서 SSD에 무거운 I/O가 몰릴 때 저전압 경고가 기록됨 → 공식 5V 5A 전원 권장
- OAuth callback의 `code`·`state`가 프록시 접근 로그에 남을 수 있음(짧은 수명·일회용)
- 감사 로그·이벤트 보존은 서버 시계 기준. 시계가 크게 틀리면 정리 시점이 어긋남
