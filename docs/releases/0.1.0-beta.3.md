# Agent Office 0.1.0-beta.3

> **상태: Beta.** Stable이 아닙니다. 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. 서버·웹 이미지는 GHCR `ghcr.io/apg0001/agent-office-server`·`agent-office-web` `0.1.0-beta.3`, Collector는 GitHub Release `collector-v0.1.0-beta.3`으로 냅니다.

대상: 0.1.0-beta.2 사용자와 새 설치자. Collector 0.1.0-beta.2는 트레이의 "업데이트 설치"로 이 버전을 받을 수 있습니다.

## 검증하지 않은 것(지원한다고 하지 않음)

- 사람이 macOS GUI 마법사를 직접 누르는 흐름(#204 수정은 러너 시험과 코드 검토까지)
- 사람이 쓰는 데스크톱에서 트레이 아이콘 표시·클릭, Gatekeeper·SmartScreen 경고 대화상자(서명 없음)
- macOS·Windows의 Codex 사용자 Hook, rpm 설치, Windows arm64, Debian 12 데스크톱 패키지

## 알려진 위험

- 코드 서명·공증이 없습니다(#42). macOS는 "개인정보 보호 및 보안 → 그래도 열기", Windows는 SmartScreen "추가 정보 → 실행".
- macOS에서 자동 시작된 Collector의 기록 파일 감시가 권한 오류를 반복합니다(Hook 수집은 정상, #184).
- Linux 설치 시험에서 트레이 종료가 늦는 간헐 실패(#177).
- 메인 화면 설치 안내는 브라우저가 GitHub API에 직접 요청합니다. GitHub에 접속할 수 없는 환경에서는 Release 페이지 링크만 보입니다.
