# Agent Office 0.1.0-beta.5

> **상태: Beta.** Stable이 아닙니다. 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. 서버·웹 이미지는 GHCR `ghcr.io/apg0001/agent-office-server`·`agent-office-web` `0.1.0-beta.5`, Collector는 GitHub Release `collector-v0.1.0-beta.5`로 냅니다.

대상: 0.1.0-beta.4 사용자와 새 설치자. Collector는 트레이 "업데이트 설치"로 받습니다.

## 바뀐 것

| 영역 | 내용 | 이슈 |
|---|---|---|
| 활동 없는 세션 숨기기 | 관리자 설정(`/admin` "사무실 화면", 기본 60분, 0이면 끔, 최대 7일). 그 시간 동안 활동이 없는 세션은 활성 세션 목록과 지도에서 빠지고 캐릭터는 퇴근, 새 활동이 오면 다시 출근. 승인 대기 세션은 숨기지 않음. 개인·팀·통합 모두 | #245 |
| 활성 세션 정렬 | 기본 상태순(승인 대기 → 일하는 중 → 쉬는 중, 같은 상태는 시작 순), 시작 순·최근 활동·이름순 선택(브라우저에 기억) | #244 |
| 캐릭터 밑 이름 | 최대 10자(넘으면 9자 + …). 목록 32자·상세 40자는 그대로 | #247 |
| Collector(macOS) | 읽기 권한이 없는 transcript를 2초마다 다시 열던 문제: 30초부터 최대 10분 간격. `status`에 단계·오류 종류(`tail_denied_open_eperm` 등, 경로 없음) | #184 |
| Collector GUI(Linux) | 창이 늦게 뜨는 동안 트레이 "종료"가 먼저 오면 창이 트레이를 다시 띄워 남던 문제 | #177 |

## 실제로 검증한 것

| 항목 | 근거 |
|---|---|
| 서버·웹 | CI(`CI Gate`, 브라우저 E2E), 서버 pytest(PostgreSQL), Vitest |
| Collector | macOS·Windows·Ubuntu 러너 Core 스모크·설치 시험, 권한 거부 재현 테스트(비root) |

## 검증하지 않은 것(지원한다고 하지 않음)

- 실제 브라우저에서 숨김 세션 캐릭터의 퇴근·재출근 연출(단위 테스트·E2E만)
- 실제 macOS launchd 환경의 권한 오류 원인(다음 `status`의 `tail_denied_*`로 확인 예정)
- 사람이 쓰는 데스크톱의 트레이·Gatekeeper·SmartScreen

## 알려진 위험

- 기본 60분이 바로 적용됩니다. 배포 직후 1시간 넘게 활동이 없던 세션은 곧바로 숨겨집니다(필요하면 `/admin`에서 0으로).
- 숨김 판정은 브라우저 시계 기준입니다. 서버와 시계 차이가 크면 그만큼 어긋납니다.
- 코드 서명·공증 없음(소유자 결정으로 하지 않음).
