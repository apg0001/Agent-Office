# Agent Office 0.1.0-beta.8

> **상태: Beta.** Stable이 아닙니다. 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. 서버·웹 이미지는 GHCR `ghcr.io/apg0001/agent-office-server`·`agent-office-web` `0.1.0-beta.8`로 냅니다. **Collector는 바뀌지 않았습니다**(최신 Collector는 `collector-v0.1.0-beta.7`).

대상: 0.1.0-beta.7 사용자. 서버·웹 이미지만 교체하면 됩니다. Collector 업데이트와 DB 마이그레이션은 필요 없습니다.

## 바뀐 것

| 영역 | 내용 | 이슈 |
|---|---|---|
| 활성 세션 목록 | PC가 2대 이상이면 PC별로 묶음: 머리줄에 가장 급한 상태 점(대기 주황·작업 초록·쉼 회색), 세션 수, 승인 대기 수(✋). 누르면 접고 펴며 브라우저에 기억 | #271 |
| 활성 세션 목록 | 같은 PC에 같은 프로젝트 세션이 2개 이상이면 프로젝트 소제목으로 묶음(이름 없는 세션은 묶지 않음). PC가 1대면 예전 목록 그대로 | #271 |
| 지도 | PC 머리줄에 마우스를 올리거나 키보드로 포커스하면 다른 PC 캐릭터를 흐리게 해 그 PC 캐릭터가 또렷해짐 | #271 |

## 실제로 검증한 것

| 항목 | 근거 |
|---|---|
| 웹 | CI(`CI Gate`, 브라우저 E2E), typecheck, Vitest 148개 |
| 화면 | 2대 PC 합성 데이터로 1400×900·390×844 스크린샷, 가로 넘침 0, 마우스 올림 강조 |

## 검증하지 않은 것(지원한다고 하지 않음)

- 실제 여러 PC가 연결된 운영 화면에서의 묶음 표시(합성 데이터로만 확인)
- 터치 기기의 머리줄 강조(마우스 올림이 없어 접기만 동작)

## 알려진 위험

- 접기 상태는 브라우저별로 저장되며 다른 기기와 공유되지 않습니다.
