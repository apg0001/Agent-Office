> **상태: Beta(2026-10-26 관리자 승인).** Stable이 아닙니다. 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. 서버·웹 이미지는 GHCR `ghcr.io/apg0001/agent-office-server`·`agent-office-web` `0.1.0-beta.2`, Collector는 GitHub Release `collector-v0.1.0-beta.2`로 냅니다.

## 검증하지 않은 것(지원한다고 하지 않음)

- 사람이 쓰는 데스크톱에서 트레이 아이콘 표시·클릭, 재로그인 후 자동 시작, Gatekeeper·SmartScreen 경고 대화상자(서명 없음, 우회 방법은 `docs/installation/collector-gui.md`)
- macOS·Windows의 Codex CLI·Desktop 사용자 Hook, 실제 OpenAI 모델 세션
- rpm 설치, Windows arm64 설치 프로그램, Debian 12 데스크톱 패키지
- macOS 관리자 암호 창·Linux polkit 창을 통한 업데이트 설치(러너에서는 같은 설치 명령을 시험용 권한으로 실행), OS 알림의 실제 화면 표시, 사람이 마법사를 직접 누르는 흐름
- 실제 GitHub 채널 Release로의 업데이트(이 릴리스부터 채널 manifest 게시)
- 72시간 연속 실행: 진행 중(#63)

## 알려진 위험

- **Collector 0.1.0-beta.1은 자체 업데이트로 이 버전을 받을 수 없습니다**(리다이렉트 버그, #44). 설치 파일이나 압축본으로 한 번 직접 설치하세요. 기존 등록·Hook은 그대로 이어집니다.
- 코드 서명·공증이 없습니다(비용 결정 대기, #42). macOS는 처음 열 때 우클릭 → 열기, Windows는 SmartScreen "추가 정보 → 실행"이 필요할 수 있습니다.
- Linux 설치 시험에서 트레이 종료가 늦는 간헐 실패가 한 번 있었습니다(#177).
- macOS에서 자동 시작된 Collector의 기록 파일 감시가 권한 오류를 반복합니다(Hook 수집은 정상, #184).
- 설치 프로그램이 일부만 바꾸고 실패하면 자동으로 되돌리지 않습니다. 같은 설치 파일을 다시 실행하세요.
- Collector의 Claude·Codex 지원 수준은 실측한 버전·OS만 `verified`입니다. 자동 업데이트된 다른 버전의 이벤트는 `inferred`로 기록됩니다(화면은 상세 패널에만 "(추정)").
