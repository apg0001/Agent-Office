# Agent Office 0.1.0-beta.10

> **상태: Beta.** Stable이 아닙니다. 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. 서버·웹 이미지는 GHCR `ghcr.io/apg0001/agent-office-server`·`agent-office-web` `0.1.0-beta.10`으로 냅니다. **Collector는 바뀌지 않았습니다**(최신 Collector는 `collector-v0.1.0-beta.9`).

대상: 0.1.0-beta.9 사용자. 서버·웹 이미지만 교체하면 됩니다. DB 마이그레이션과 Collector 업데이트는 필요 없습니다.

## 바뀐 것

| 영역 | 내용 | 이슈 |
|---|---|---|
| 사무실 크기 | 터미널을 닫는 등 종료 신호 없이 멈춘 세션이 책상을 계속 차지해 새 세션마다 책상 줄이 늘던 문제 수정. 활동 없는 세션 숨기기 기준(관리자 설정, 기본 60분, 승인 대기 제외)을 넘긴 세션의 책상은 새 세션이 재사용 | #291 |
| 지도 | 책상 줄 수를 숨긴 뒤 보이는 세션 기준으로 정해, 숨겨진 세션 때문에 사무실이 넓어지지 않음 | #291 |
| 팀·통합 화면 | 책상 순번에서 오래 조용한 세션을 건너뜀 | #291 |

세션 자체를 종료로 바꾸지는 않습니다. 멈췄던 세션이 다시 활동하면 다시 나타나고 새 책상을 받습니다.

## 실제로 검증한 것

| 항목 | 근거 |
|---|---|
| 서버 | pytest(PostgreSQL): 조용한 세션 책상 재사용·승인 대기 유지·재활동 시 새 책상·팀 순번, 전체 통과 |
| 웹 | typecheck, Vitest 148개, CI(`CI Gate`, 브라우저 E2E) |

## 검증하지 않은 것(지원한다고 하지 않음)

- 운영 DB에 쌓인 정체 세션 수(직접 조회하지 않음). 배포 뒤 새 세션이 들어오면서 책상이 재사용되어 줄어듭니다

## 알려진 위험

- 숨기기 설정을 0(끔)으로 두면 예전처럼 책상을 재사용하지 않습니다.
- 60분 넘게 조용히 생각만 하는 세션은 책상을 내줄 수 있습니다(숨기기와 같은 기준).
