# Agent Office 0.1.0-beta.6

> **상태: Beta.** Stable이 아닙니다. 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. 서버·웹 이미지는 GHCR `ghcr.io/apg0001/agent-office-server`·`agent-office-web` `0.1.0-beta.6`, Collector는 GitHub Release `collector-v0.1.0-beta.6`으로 냅니다.

대상: 0.1.0-beta.5 사용자와 새 설치자. Collector는 트레이 "업데이트 설치"로 받습니다.

## 바뀐 것

| 영역 | 내용 | 이슈 |
|---|---|---|
| 앱으로 설치(PWA) | 웹 앱 매니페스트와 서비스 워커. 폰 홈 화면·Windows·macOS 앱 아이콘으로 설치해 주소창 없이 연다. 기기에는 정적 파일(화면 코드·글꼴·그림)만 캐시하고 `/api/`·화면 HTML은 캐시하지 않는다 | #255 |
| 앱 아이콘 | 왕관 쓴 리드 캐릭터 픽셀아트(머리 위 말풍선·책상). 192·512·maskable·apple-touch·파비콘 | #255 |
| 반응형 사무실 화면 | 창 크기·화면 회전·전체 화면 전환에 맞춰 지도 크기를 바꿈(높이는 화면의 72%, 300~560px). 너비 720px 이하·높이 500px 이하에서 활성 세션 목록을 지도 아래로, 전체 화면에서는 작게 겹침. 두 손가락 확대·축소. 폰에서 표는 표 안에서만 가로 스크롤 | #255 |
| Collector `status` | 읽을 수 없는 기록 파일(`tail_denied_open_eacces`)이 있으면 원인(다른 사용자·sudo로 실행한 세션)과 소유자 되돌리기 안내. 문서에 복구 명령 | #184 |

## 실제로 검증한 것

| 항목 | 근거 |
|---|---|
| 서버·웹 | CI(`CI Gate`, 브라우저 E2E), Vitest, vite build |
| PWA | headless Chromium `Page.getInstallabilityErrors` 오류 없음, 서비스 워커 활성, 캐시에 `/api/` 응답 없음 |
| 반응형 | 320×568·390×844·844×390·768×1024·1024×700·1400×1000, 세로·가로 전체 화면, 회전 스크린샷(가로 넘침 없음) |
| Collector | macOS·Windows·Ubuntu 러너 Core 스모크·설치 시험 |

## 검증하지 않은 것(지원한다고 하지 않음)

- 실제 Android·iPhone·Windows·macOS 기기의 PWA 설치와 홈 화면 아이콘 표시
- 실제 터치 기기의 핀치 확대(headless 터치 에뮬레이션 없음)
- 사람이 쓰는 데스크톱의 트레이·Gatekeeper·SmartScreen

## 알려진 위험

- PWA 설치는 HTTPS 주소에서만 됩니다(Tailscale Funnel 등).
- 서비스 워커는 배포 후 첫 접속에 등록되고, 다음 배포 때 새 화면 코드는 새로고침 한 번 뒤에 반영될 수 있습니다(HTML은 캐시하지 않음).
- 코드 서명·공증 없음(소유자 결정으로 하지 않음).
