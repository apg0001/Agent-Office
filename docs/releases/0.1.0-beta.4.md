# Agent Office 0.1.0-beta.4

> **상태: Beta.** Stable이 아닙니다. 아래 "검증하지 않은 것"은 지원한다고 하지 않습니다. 서버·웹 이미지는 GHCR `ghcr.io/apg0001/agent-office-server`·`agent-office-web` `0.1.0-beta.4`, Collector는 GitHub Release `collector-v0.1.0-beta.4`로 냅니다.

대상: 0.1.0-beta.3 사용자와 새 설치자. Collector 0.1.0-beta.2·beta.3은 트레이의 "업데이트 설치"로 받을 수 있습니다.

## 바뀐 것

| 영역 | 내용 | 이슈 |
|---|---|---|
| Windows Codex | Codex가 Hook을 세션 셸(PowerShell)로 실행해 `"…exe" hook codex`가 문법 오류로 매번 실패(`hook exited with code 1`)하던 문제. Hook 명령을 설치 폴더 8.3 짧은 경로·따옴표 없는 형식으로 만들어 PowerShell·cmd·Git Bash 어디서나 같은 뜻으로 실행. **업데이트 후 Codex에서 한 번 다시 신뢰 필요** | #225 |
| 작업 폴더 이름 | 기본 켜짐(팀 사무실 "(이름 없음)" 해소). 업데이트한 PC도 켜짐, `settings workspace-name off`로 끔. 보내는 값은 그대로 마지막 폴더 이름 하나 | #221 |
| 팀·통합 사무실 | 세션 하나가 끝나면 책상 번호가 당겨지는데 클라이언트가 그 갱신을 버려 대장 둘이 같은 책상·같은 옷 색이 되던 문제. 연결 동안 책상 고정, change_seq가 그대로인 값 변경은 스냅샷으로 | #231 |
| 사무실 | 활성 세션 목록에서 고르면 그 캐릭터를 따라가고 발밑 고리·노란 이름표로 강조 | #223 |
| 사무실 | 쉬는 캐릭터 머리 위 연출: 소일거리(커피·간식·폰·스트레칭·음악·신문·화분·게임 등), 옆에 쉬는 캐릭터가 있으면 수다, 5분 조는 중, 15분 자는 중(브라우저 연출, 서버 전송 없음) | #233 |
| 사무실 | 테스트 구역 실험실: 플라스크 거품·시험관·현미경·결과 화면·랙 LED·체크 바닥 | #235 |
| 계정 화면 | 팀·PC·계정·관리 화면에 사무실과 같은 상단 바와 "사무실로 돌아가기", 표 구분선 어긋남 수정 | #227 |
| 문서 | README 최신화 | #229 |

## 실제로 검증한 것

| 항목 | 근거 |
|---|---|
| 서버·웹 | CI(`CI Gate`, 브라우저 E2E), Vitest, 팀·실시간 서버 테스트(PostgreSQL) |
| Windows Hook 명령 | GitHub Actions Windows 러너에서 짧은 경로·따옴표 없는 명령 생성, 설치 프로그램 이전 실측(`hooks_unquoted_any_shell`) |
| Collector | macOS·Windows·Ubuntu 러너 Core 스모크·설치 시험(게시 워크플로) |

## 검증하지 않은 것(지원한다고 하지 않음)

- 실제 Windows PC의 PowerShell 세션에서 Codex Hook 실행(소유자 PC에서 이 버전으로 확인 예정), 8.3 짧은 이름이 꺼진 볼륨(그때는 이전 따옴표 형식으로 써서 PowerShell에서는 실패)
- 사람이 쓰는 데스크톱의 트레이·Gatekeeper·SmartScreen, macOS·Windows Codex 장기 사용

## 알려진 위험

- 코드 서명·공증 없음(#42). macOS "그래도 열기", Windows SmartScreen "추가 정보 → 실행".
- Windows Codex 사용자는 업데이트 뒤 Hook 명령이 바뀌어 Codex에서 다시 신뢰해야 수집됩니다.
- macOS 자동 시작 Collector의 기록 파일 감시 권한 오류(#184), Linux 트레이 종료 간헐 실패(#177).
