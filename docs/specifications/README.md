# 기준 사양 보존 정책

이 디렉터리는 Agent Office 구현의 출발점이 된 원문 사양을 버전별 불변
스냅샷으로 보존합니다. 요약 문서나 GitHub Issue는 실행 가능한 작업 단위이지만,
원문의 세부 제약과 문맥을 대체하지 않습니다.

SHA-256은 UTF-8 원본 파일의 바이트를 대상으로 계산했습니다. 저장소 사본은 외부
원본과 동일한 바이트여야 하며 `tests/test_specification_baseline.py`가 이를 검사합니다.

## 변경 규칙

- v0.8 파일은 오탈자까지 포함해 직접 수정하지 않습니다.
- 사양을 변경할 때는 Issue와 ADR을 먼저 만들고 새 버전 파일을 추가합니다.
- 이후 사용자 결정, 승인된 ADR 또는 더 최신 버전 사양이 v0.8과 충돌하면 이후
  결정이 우선하며, 변경 이유와 영향을 요구사항 추적표에 기록합니다.
- 구현 이슈는 관련 요구사항 ID와 이 기준선 문서 링크를 함께 남깁니다.
- 세션 로그나 실제 사용자의 프롬프트·코드·도구 출력은 이 디렉터리에 보존하지
  않습니다. 이 파일은 사용자가 제공한 제품 개발 사양만을 보존합니다.
